# Ask Naval Lens 微信小程序

这是 Ask Naval Lens 的原生微信小程序 MVP。第一版只提供中文，不要求 ChatGPT 账号，不包含注册、历史记录或支付。

## 已实现

- 真实问题输入与 6 个主题
- 每周免费额度显示
- DeepSeek 中文结构化分析
- 核心判断、相关框架、适用边界、3 个行动与追问
- Naval 原始出处复制
- 有帮助 / 没说到点上反馈
- 分享完整分析前的隐私确认
- 关于、隐私、免责声明与中文联系邮箱
- `wx.login` 会话；未配置正式 AppID 时可使用匿名开发调试模式
- 请求幂等键，避免网络重试重复生成与重复扣次

DeepSeek API Key、微信 AppSecret 和会话签名密钥都只存在服务端，不会进入小程序代码包。

## 用微信开发者工具打开

1. 安装最新版微信开发者工具。
2. 选择“导入项目”。
3. 项目目录选择本文件所在的 `wechat-miniprogram` 文件夹。
4. 现在的 `project.config.json` 使用 `touristappid`，可用于界面开发；有正式小程序后，在开发者工具“详情 → 基本信息”中换成正式 AppID。工具会将个人设置写入已被 Git 忽略的 `project.private.config.json`。
5. 开发联调时，可在“详情 → 本地设置”临时勾选“不校验合法域名、TLS 版本及 HTTPS 证书”。这个选项只用于开发，提审前必须关闭。

当前接口地址集中写在：

```text
miniprogram/config.js
```

以后换已备案域名时，只需要修改这里的 `API_BASE_URL`。

`USE_WECHAT_SESSION` 当前为 `false`，用于 `touristappid` 开发预览；此模式仅用匿名设备标识，免费额度不是强身份边界。换成正式 AppID、完成后端 4 个环境变量后，提审构建必须把它改成 `true`。开启后，小程序会明确标识自身并强制使用 `wx.login` 会话；生产后端不会静默降级。

## 正式微信登录

服务端需要配置 4 个环境变量：

```ini
WECHAT_APP_ID=正式小程序AppID
WECHAT_APP_SECRET=正式小程序AppSecret
MINI_SESSION_SECRET=至少32字符的独立随机密钥
WECHAT_SUBJECT_SECRET=至少32字符的长期独立随机密钥
```

小程序调用 `wx.login`，服务端再向微信交换 openid，并只向客户端签发短期会话令牌。AppSecret、session_key 和 openid 原值都不会返回客户端。`WECHAT_SUBJECT_SECRET` 用于稳定识别同一微信用户，应与会话签名密钥分开保存，不能随意轮换，否则已有用户会被识别为新用户。

未配置这 4 项时，`touristappid` 构建仍可通过匿名设备标识联调，但额度不能被视为强身份边界。正式构建开启 `USE_WECHAT_SESSION` 后，带小程序标识的请求始终要求有效微信会话，不会因少配某个变量而降级。正式发布前必须启用微信登录。

## 正式发布前的域名阻塞项

微信要求 `wx.request` 使用预先配置的 HTTPS 合法域名，证书有效、支持 TLS 1.2+，并且服务端域名需要 ICP 备案。当前托管地址：

```text
https://ask-naval-lens.fancifulman.chatgpt.site
```

可以用于当前开发联调，但不能先假定它能够通过微信后台的合法域名校验。正式提审前应准备一个自己可控制、已备案的专用 HTTPS API 域名，并在“小程序后台 → 开发 → 开发设置 → 服务器域名”中加入 `request` 合法域名。

小程序本身还需要单独完成小程序备案；它和服务器域名备案是两件事。

## 隐私与分享

- 首页在提交前要求用户确认隐私说明。
- 不申请手机号、头像、位置、相册等不必要权限。
- 问题会发送到后端并由 DeepSeek 模型服务处理。
- 问题和分析结果计划保留 90 天，并在此后的系统维护中删除；用户可通过 `2685897@qq.com` 申请提前删除。
- 结果页默认隐藏右上角分享，用户确认“对方可看到原问题与完整分析”后才显示分享按钮。
- 分享标题不包含用户问题；分享路径只包含不可枚举的分析 ID；卡片固定使用本地 5:4 品牌图，不读取当前页面截图。
- 外部 `nav.al` 来源不依赖 web-view，使用“复制原文链接”。

## 联调检查

- 首页能读取每周剩余额度。
- 8–3000 字问题与主题校验正确。
- 分析中按钮不可重复点击。
- 400、401、402、409、429、503、超时和断网都有可理解提示。
- 成功后额度立即减少，刷新后保持一致。
- 1–3 个框架、3 个行动、无前提说明、长文本都不溢出。
- 好友通过分享路径能打开同一份结果，分享卡片不泄露问题。
- iOS、Android 真机和系统大字体下都完成检查。
- 提审前关闭“不校验合法域名”。

## 发布流程

开发者工具模拟器 → iOS/Android 真机预览 → 上传代码 → 体验版 → 完善隐私指引与备案 → 提交审核 → 审核通过后发布。

正式上传需要：正式 AppID、已被添加为开发成员的微信号，以及小程序管理员在公众平台完成相关配置。本仓库不会保存代码上传密钥或 AppSecret。
